钉钉工具箱 · 使用说明
==================================================

【是什么】
双击 dingtalk_box.exe，自动拉取当天钉钉消息，AI 整理成日报，发给您自己。
内置 Qwen AI，开箱即用，不需要自己申请 API key。


【5 步上手】

1. 解压本压缩包到任意目录（桌面 / D 盘都行，不要放 ProgramFiles）

2. 双击 dingtalk_box.exe
   首次启动会自动准备好内置 Qwen key（不需要任何配置）

3. 登录钉钉
   工具里点"登录钉钉" → 自动打开钉钉授权网页 → 用钉钉 App 扫码
   （只需要登录一次，token 会在本机缓存 7 天左右）

4. 生成日报
   - 顶部选日期（默认今天）
   - 点"生 成 日 报"（约 1-2 分钟）
   - 完成后弹"📤 发送钉钉"确认框
   - 点确认 → 钉钉收到一条文件消息（就是您自己）

5. （可选）用自己的 API Key
   工具里点"AI 配置" → 选厂商（阿里云百炼）→ 选模型
   → 填 API key → 点"测试连接"（绿勾 OK）
   → key 自动加密保存到本机
   不填也行，默认用内置 Qwen key


【功能速查】

- 今日日报：拉当天 → AI 整理 → PNG + MD → 发自己
- 生成 X 日报：选历史日期（同样流程）
- 历史日报：列出已生成的，点"预览"看 MD / PNG
- AI 配置：选模型 / 填自定义 key / 测试连接
- 诊断：右上角"诊断"按钮 → 复制到剪贴板，方便反馈问题


【常见问题】

Q: 启动后白屏 / 闪退？
A: 检查是不是 Windows 10 以下系统。本工具需要 Windows 10/11。
   也可右键 dingtalk_box.exe → "以管理员身份运行"试一次。
   v0.3.12 之前（v0.3.10 / v0.3.11）的版本首次启动可能会闪退——
   是 sidecar 配置层死循环 bug，v0.3.12 已修复，必升级。

Q: 启动后没有自动绑定 Qwen 模型？
A: v0.3.8+ 首次启动会自动把 exe 旁的 .env 复制到
   %APPDATA%\DingTalkBox\.env。v0.3.9+ 内置 key 是密文
   （`enc:v1:` 前缀，Argon2id + AES-256-GCM 加密），工具
   启动时自动解密注入，正常看不到明文。v0.3.13 已修复
   .env 注释行少换行符导致的「未配置模型」bug，重启即可。
   如启动报错，按"诊断"按钮复制错误日志给负责人。

Q: 状态栏显示"未登录"？
A: 工具里点"登录钉钉" → 扫码。token 本机缓存约 7 天。

Q: 提示"未识别当前登录人，请先 dws auth login"？
A: 同上，重新扫码登录。

Q: 提示"DPAPI 解密失败" / "密钥已备份为 .bak"？
A: 第一次用不会有这提示。如果突然出现，说明你换过 Windows 账号。
   进 AI 配置 → 重新填一次 API key 即可。

Q: 生成的图发不出去？
A: 看错误卡片的"详情"或底部的"完整响应路径"（dump: 开头），
   把那段文字发给工具负责人。

Q: 能发给其他人吗？
A: 不能。本工具只发给您当前登录的钉钉账号自己。
   如需分享，从钉钉里手动转发那条文件消息即可。

Q: 日报保存在哪？
A: 工具顶部点"打开文件夹"，会跳到本机的输出目录。
   文件名格式：钉钉工作纪要日报-YYYY-MM-DD.png / .md

Q: 怎么改 AI 模型？
A: AI 配置 → 选厂商"阿里云百炼" → 选模型
   可选：qwen3.5-flash（默认，速度快）/ qwen3.7-max（最强）/
         qwen3.7-plus（通用主力）/ qwen3.6-plus（增强版）/
         qwen3.6-flash（增强版极速）/ qwen-long（超长上下文）


【文件位置】

- 本工具配置/缓存/日报：C:\Users\<您的用户名>\AppData\Roaming\DingTalkBox\
- 内置 key 配置文件：  C:\Users\<您的用户名>\AppData\Roaming\DingTalkBox\.env
- dws 安装路径：       C:\Users\<您的用户名>\AppData\Roaming\DingTalkBox\bin\
- 卸载 = 直接删除整个 DingTalkBox 文件夹（无注册表/服务残留）
